ZA.CC AUCTION BASED TOURNAMENT – SEASON 2

Included:
- Mobile-friendly auction management app (index.html)
- 8 editable team slots, 100,000 points each
- Six-player squad limit per team
- Player registration, base prices, roles and contact details
- IPL-style manual live bidding controls, sold/unsold, undo
- Team purse/squad dashboard, auction history, CSV export
- Backup and restore
- Read-only display screen

IMPORTANT LIMITATION:
This starter version stores data in the browser's local storage. It works on the same browser/device and can update another tab in that same browser. It is NOT yet a true internet-wide synchronized multi-device auction. Do not use it as a public multi-device live auction until a shared database/realtime backend is connected.

FREE STATIC HOSTING:
You can publish the files free using GitHub Pages:
1. Create/sign in to GitHub.
2. Create a new public repository named zacc-auction.
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to publish. Your site URL will appear in Settings > Pages.

Security note:
The default PIN prompt in this starter is a convenience lock only, not strong server-side authentication. Do not add sensitive personal data. A real secure admin login and shared database are required for a production multi-device system.
